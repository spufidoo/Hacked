================================================================================
  QUICK GUIDE: Installing HackedSSH on Heimdall (Raspberry Pi)
================================================================================

OPTION 1: AUTOMATED INSTALLATION (Recommended)
===============================================

From Thor (or your current machine):
-------------------------------------

1. Copy files to Heimdall:
   
   scp -r /home/marcus/Code/python/Hacked pi@heimdall:~/
   
   Or use rsync (better):
   
   rsync -avz --progress /home/marcus/Code/python/Hacked/ pi@heimdall:~/Hacked/

2. SSH into Heimdall:
   
   ssh pi@heimdall

3. Run the automated installer:
   
   cd ~/Hacked
   sudo bash scripts/install_on_raspberry_pi.sh

4. Follow the prompts and you're done!

================================================================================

OPTION 2: MANUAL INSTALLATION
==============================

On Heimdall:
------------

1. Update system:
   sudo apt update && sudo apt upgrade -y

2. Install Python dependencies:
   sudo pip3 install folium geoip2 jinja2 systemd-python configparser

3. Install web server:
   sudo apt install nginx -y
   sudo systemctl enable nginx
   sudo systemctl start nginx

4. Install mail server:
   sudo apt install postfix mailutils -y

5. Install security tools:
   cd ~/Hacked
   sudo bash scripts/install_security_tools.sh

6. Install HackedSSH service:
   sudo bash scripts/install_hackedssh_service.sh

7. Configure for Heimdall:
   sudo nano /usr/local/bin/HackedSSH.ini
   
   Update:
   sender_email = heimdall@davage.me
   hostname = heimdall.local
   report_url = http://heimdall.local/HackedSSH_Report.html

8. Test:
   sudo systemctl start hackedssh.service
   sudo journalctl -u hackedssh.service -f

================================================================================

FIREWALL CONFIGURATION (IMPORTANT!)
====================================

Heimdall is a gateway - be careful with firewall!

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw default allow routed        # CRITICAL for gateway!

sudo ufw allow from 192.168.1.0/24 to any port 22  # SSH from local network
sudo ufw allow 80/tcp                # HTTP
sudo ufw allow 443/tcp               # HTTPS

# If Heimdall is DNS server:
sudo ufw allow 53/tcp
sudo ufw allow 53/udp

# If Heimdall is DHCP server:
sudo ufw allow 67/udp
sudo ufw allow 68/udp

sudo ufw enable
sudo ufw status verbose

================================================================================

TROUBLESHOOTING
===============

Service won't start:
   sudo journalctl -u hackedssh.service -n 100
   sudo systemctl status hackedssh.service

Email not sending:
   sudo systemctl status postfix
   sudo tail -f /var/log/mail.log
   mailq

High temperature:
   vcgencmd measure_temp
   # If >80°C: improve cooling, reduce services

Disk full:
   df -h
   sudo journalctl --vacuum-size=50M
   sudo apt clean

Check dependencies:
   pip3 list | grep -E 'folium|geoip2|jinja2'
